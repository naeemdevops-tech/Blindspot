# BlindSpot

BlindSpot is an offline-first personal finance and liquidity tracking mobile app built to give you complete visibility over cash balances, credit card exposures, and recurring installment obligations without sending your data to the cloud.

## Key Features

- **Liquid Balance Monitoring:** Real-time visibility into available liquid reserves and bank balances.
- **Credit & Debt Tracking:** Track revolving balances, due dates, and exposure limits.
- **Installment (EMI) Management:** Organize fixed recurring installments and payment cycles.
- **Encrypted Local Storage:** All records are stored locally on the device using an encrypted SQLite database.
- **100% Offline:** Zero account sign-ups, zero third-party telemetry, and no remote server dependencies.

## Android Installation Guide

1. Download `app-release.apk` from the latest release.
2. Tap the file in your notification center or file manager.
3. If your browser or file manager prompts that installation is blocked:
   - Tap **Settings**.
   - Enable **Allow from this source**.
4. If Google Play Protect shows an unrecognized developer warning:
   - Tap **More details**.
   - Tap **Install anyway**.
5. Launch **BlindSpot** and configure your security PIN.
