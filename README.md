# BlindSpot 💳📊

BlindSpot is a lightweight, privacy-focused financial management tool built to track liquid cash balances, credit card liabilities, and recurring installments.

## 📥 Download
Get the latest build directly from the [Releases](https://github.com/<your-username>/blindspot/releases) tab.

## 🔒 Security & Architecture
- **Framework:** Flutter & Dart
- **Storage:** Encrypted Local SQLite
- **Network:** Zero telemetry, 100% offline-ready
